# 오브 소개·콘텐츠 정리 — 2026-10-26

## 유지한 구성

- 메뉴 순서: REPORT → CONTENTS → SNS → FINAL PROJECT → BRAND → SERVICE.
- 기존 7개 주요 페이지의 최상위 섹션 종류와 순서, 색상 토큰, 폰트, 2열 콘텐츠 갤러리, 브랜드 로고·팔레트, 기존 조사 자료를 유지했다.
- 신규 안내는 기존 섹션 내부에 추가했다. 기존 공통 스타일은 수정하지 않고 `css/content-update.css`에 소개·상태·자료 대기 영역에 필요한 최소 스타일만 추가했다.
- 별도 Sites 배포를 재개하지 않는다. 반영 대상은 기존 GitHub 저장소다.

## 변경 파일과 내용

| 파일 | 변경 |
| --- | --- |
| `index.html` | 요청한 메인 제목·소개, AI 가상 인물 고지, 오브·모아 소개. 활동 기록은 보조 설명으로 유지 |
| `brand.html` | 인간 관찰·데이터 학습 표현 교체, 성격·주제·말투 가이드, 모아 소개와 최종 이미지 대기 영역 |
| `contents.html` | 실제 콘텐츠 7건, 유형·제작 상태, 게시일·설명·공식 링크, 공개 전 작업 구분 |
| `js/contents.js` | 기존 유형 필터에 상태 필터를 조합. 결과가 없으면 안내 표시 |
| `data/content-catalog.json` | 검증한 콘텐츠·날짜·링크·썸네일 기록. 현재 정적 HTML의 근거 목록이며 자동 렌더링 파일은 아님 |
| `sns.html` | 예시 성과 삭제, 공개 콘텐츠 구성과 3개 영상의 확인일 기준 공개 조회 수. 내부 인사이트는 대기 상태 |
| `report.html` | 기존 자원·표·상세창 보존, 자료 조사→기획→범어사 콘텐츠 연결, 미확인 후기의 출처 고지 |
| `final.html` | 이름·기간·팀·기여도·결과물의 허위 자리표시자를 확인 대기 상태로 정리 |
| `service.html` | 별도 Hidden Spot 프로토타입의 화면 구현·실제 확인 동작·기획/연동 미확인 기능 구분, 근거 없는 후기 제거 |
| `components/footer.html` | 개인 이름을 추정하지 않고 OVE 아카이브 명칭 사용. 기존 SNS 링크 보존 |
| `cardnews.html` | 편집기 구조·기능을 유지하고 페이지 제목·검색·공유 설명 수정 |
| `css/content-update.css` | 기존 토큰을 사용하는 작은 소개·필터·대기 영역 스타일 |
| `README.md` | 임시 운영자명 교체 안내 갱신 |
| `data/chatbot.json` | 로컬에서 기존 작업 중인 안내 챗봇의 소개·목록·성과 설명을 새 방향에 맞게 동기화. 챗봇 기능·접수 설정은 변경하지 않음 |

## 추가로 필요한 자료

1. 오브·모아의 최종 캐릭터 원본, 사용 가능한 대표 이미지. 임의 새 캐릭터 생성은 하지 않음.
2. 부산국제영화제·범어사 카드뉴스의 최종 표지 파일. 영상은 채널에서 확인한 공식 원격 썸네일을 사용하며, 장기 운영에는 승인된 로컬 썸네일 파일이 있으면 좋음.
3. 도달, 노출, 저장, 공유, 평균 시청 시간·완주율 등의 원본 인사이트와 집계 기간·채널·측정 시각. 서로 다른 플랫폼 조회 수를 합산하지 않음.
4. 국밥 브이로그의 플랫폼별 정확한 게시 시각(사용자 기록 10/21, Instagram 메타 10/20).
5. 최종 프로젝트명, 기간, 팀원, 담당 역할, 확정 결과물과 성과 근거.
6. 공개할 실제 운영자명/운영 조직명. 계정명만으로 운영자의 실명이나 법적 주체를 추정하지 않음.
7. Hidden Spot의 구현 명세·데이터 출처·실제 연동 범위, 검증 기록과 동의받은 후기 원문.
8. 외부 Instagram·YouTube 프로필에도 예전 AI 관광 조사원·인간 관찰 설정이 남아 있어 별도 채널 소개 갱신 필요. 이번 작업에서는 외부 프로필을 편집하지 않음.

## 검증

- 1440 / 390 / 320px에서 주요 7페이지, 총 21개 화면: 가로 넘침 및 확인된 깨진 이미지 없음.
- 유형 3종 × 상태 4종, 총 12개 필터 조합: 공개 5 / 기획 2, 카드뉴스 4 / 영상 3. 제작 중 0건에 빈 상태 표시 확인.
- 모바일 메뉴 이동 및 리포트 상세창·후기 탭·닫기 확인.
- HTML 태그 중첩·중복 ID·로컬 파일 참조, 공통 메뉴·푸터 동기화, JavaScript 문법, `git diff --check` 확인.
- 수정 전 로컬 파일과 비교해 주요 7페이지의 메뉴와 최상위 섹션 순서가 동일함을 검사.
- 기존 작업 중인 등록형 챗봇 테스트 통과. 문의 DB 미연결 상태와 기존 설정 유지.
